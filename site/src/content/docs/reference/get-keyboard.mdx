## Overview

`searchField` and `textField` already take `value`, `defaultValue` and `onTextChange`, which
cover most needs. `getKeyboard` is the escape hatch: the TVML Keyboard feature itself.

```tsx
const field = useRef<TVMLElement>(null);
// …
const keyboard = getKeyboard(field.current!);
if (keyboard) keyboard.text = "";
```

It returns `undefined` until the field is in a presented document.
