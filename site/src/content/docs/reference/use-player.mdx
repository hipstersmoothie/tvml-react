## Overview

```tsx
const player = usePlayer();

<lockup
  onSelect={() =>
    player.play({ url, title: "Episode 1", subtitle: "Show", artworkImageURL: art })
  }
/>;
```

Inside a `PlayerProvider` (pass it to `launch`'s `wrapper`), every screen shares one player.
Without one, each `usePlayer` call owns a player that stops when the component unmounts.

The item's `title`, `subtitle` and artwork are what AVKit publishes to Now Playing; there's
nothing else to set up.

<Note>
Menu during audio returns to your app with the audio still playing, and TVJS reports nothing.
`state` stays `"playing"`; call `present()` to show the player again. Menu during video ends
it, with an `itemEnd` reason of `"userInitiated"`.
</Note>
