## Overview

```tsx
const { reduceMotion, voiceOver } = useAccessibility();
const rotate = !reduceMotion;
```

Respect `reduceMotion` in anything that moves on its own and `reduceTransparency` in translucent
panels. Needs an app launched with `TVMLReact.launch`.
