## Overview

`Screen` renders the `divTemplate` your rows go in. Text in a `divTemplate` is black unless you
color it, whatever the theme or system appearance, so `Screen` gives every `Cell` a default
color: white, or black with `theme="light"`.

<Example name="screen-background" props={{ photo: "https://example.com/photo.jpg" }} />

<Note kind="Important">
A `divTemplate`'s background is read once, when the screen is presented. To change the
photo, present a new screen with `useNavigation().replace()`.
</Note>

## Sizes

`tvml-react/layout` also exports the numbers to plan widths with:

| Constant | Value | |
| --- | --- | --- |
| `SCREEN_WIDTH` | 1920 | The screen, in points. |
| `SCREEN_HEIGHT` | 1080 | |
| `SAFE_X` | 90 | Apple's TV-safe inset at the sides. |
| `SAFE_Y` | 60 | At the top and bottom. |
| `CONTENT_WIDTH` | 1740 | The width rows align within. |
