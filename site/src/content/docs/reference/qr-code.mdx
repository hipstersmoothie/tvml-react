## Overview

<Example name="qr-code-signin" />

Size it with `style`. `foreground` and `background` take `#rrggbb` or `#rrggbbaa` colors. Needs an app launched with `TVMLReact.launch`, which registers it.

## Placing it

Give it a size with `style` and a place with `position` (`center`, `bottom-right`, …), which sets
`tv-position` and the matching `tv-align`. Native elements don't render inside a `<row>`: put
them directly in the `divTemplate`, or in a layout [`Stack`](/reference/stack/) or
[`Box`](/reference/box/), as the Avatar example does.
