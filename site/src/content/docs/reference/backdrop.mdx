## Overview

TVML's `<background>` can't change once a screen is up. `Backdrop` can: change `src` and it
cross-fades to the new image.

<Example name="backdrop-dim" />

Render it first in a `divTemplate`; it covers the whole screen behind everything else and takes
no layout space. Needs an app launched with `TVMLReact.launch`, which registers it.
