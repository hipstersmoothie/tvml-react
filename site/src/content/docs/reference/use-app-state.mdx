## Overview

```tsx
const state = useAppState(); // "active" | "background"

useAppEvent("resume", () => refetchScores());
useAppEvent("suspend", () => saveProgress());
```

`getAppState` and `onAppStateChange` are the same outside React. `reloadApp` restarts your
JavaScript app by re-running the bootstrap, now or the next time the app resumes.
