## Overview

```tsx
import { TVMLQueryProvider } from "tvml-react/query";

launch(<App />, { wrapper: TVMLQueryProvider });
```

It installs the TVJS integration (queries refetch when the app resumes and when the network
returns) and provides a client that retries once and keeps data fresh for 30 seconds. Pass your
own `client` to change that.

With your own `QueryClientProvider`, call `installQueryIntegration()` once before rendering.
