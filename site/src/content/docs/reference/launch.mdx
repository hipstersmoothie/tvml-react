## Overview

Call `launch` from the `start` function your bundle exports. The bootstrap `Application.js`
that `tvml-react dev` and `build` write calls `start` once the bundle has loaded.

```tsx
import { launch, type StartOptions } from "tvml-react";

import { App } from "./App";

export function start({ baseUrl }: StartOptions) {
  launch(<App apiBase={baseUrl} />, { errorTitle: "Something went wrong" });
}
```

Every screen (the root, pushed screens, modals, tabs and overlays) has its own error boundary.
A screen that throws while rendering shows an alert with the error and a Try Again button, and
the rest of the app keeps working.

## Returns

The root, with `render`, `unmount` and its `document`. If launching throws, `launch` reports
the error to `onError`, presents an alert with it, and returns `undefined`.
