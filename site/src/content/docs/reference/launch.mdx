## Overview

Call `launch` from the `start` function your bundle exports. The bootstrap `Application.js`
that `tvml-react dev` and `build` write calls `start` once the bundle has loaded.

```tsx
import { launch, type StartOptions } from "tvml-react";

import { App } from "./App";

export function start({ baseUrl }: StartOptions) {
  launch(<App apiBase={baseUrl} />, { errorTitle: "Something went wrong" });
}
```

Every screen (the root, pushed screens, modals, tabs and overlays) has its own error boundary.
A screen that throws while rendering shows an alert with the error and a Try Again button, and
the rest of the app keeps working.

## Options

<Prop name="wrapper" type="ComponentType | ComponentType[]">
Wraps the app and every screen pushed with `useNavigation()` in one tree. Put context
providers here (a `QueryClientProvider`, a `PlayerProvider`) so pushed screens can see them.
An array is composed outermost first.
</Prop>
<Prop name="errorTitle" type="string">Title of the default error alert.</Prop>
<Prop name="renderError" type="(error: unknown, retry: () => void) => ReactNode">What a screen shows when it throws while rendering.</Prop>
<Prop name="onError" type="(error: unknown) => void" default="console.error">Called for every error React reports.</Prop>
<Prop name="onUncaughtError" type="(error: unknown) => void">Errors no boundary caught. Defaults to `onError`.</Prop>
<Prop name="identifierPrefix" type="string">Prefix for ids generated by `useId`.</Prop>

## Returns

The root, with `render`, `unmount` and its `document`. If launching throws, `launch` reports
the error to `onError`, presents an alert with it, and returns `undefined`.
