## Overview

Each line of the columns becomes a row of fixed-width cells, so the columns line up, and cells
with the same background touch to read as one tile per column. Use it when every column needs
a fill; organizers (and so [`Stack`](/reference/stack/)) can't draw one.

<Example name="columns-forecast" />

## Properties

<Prop name="columns" type="Array<Column>">
Each column: a `key`, a `width`, its `lines` top to bottom, and optionally `align`, `offset`
and `background`.
</Prop>
<Prop name="lineStyles" type="Array<TextStyle>">
The style of each line, shared across columns: `size`, `weight`, `color`, `background`,
`height`, `lines`.
</Prop>
<Prop name="region" type="Region">The region the rows go in. Also takes `align`, `gap`, `bleed`, `marginTop` and `marginBottom`, like `Row`.</Prop>
