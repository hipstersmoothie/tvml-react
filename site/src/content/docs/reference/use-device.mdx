## Overview

```tsx
const { model, systemVersion, appVersion } = useDevice();
const { language, storefrontCountryCode, restrictions } = usePlatformSettings();

const allowed = movies.filter((movie) => restrictions.allowsExplicit !== false || !movie.explicit);
```

`restrictions` reflects Settings → General → Restrictions, for hiding content a household has
restricted.
