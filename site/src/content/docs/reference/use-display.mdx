## Overview

```tsx
const { scale, hdr } = useDisplay();
const stream = hdr ? item.hdrUrl : item.sdrUrl;
const art = scale > 1 ? item.art2x : item.art;
```

Needs an app launched with `TVMLReact.launch`.
