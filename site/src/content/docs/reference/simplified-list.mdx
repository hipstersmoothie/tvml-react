## Overview

A `UITableView` for long lists in a free-form screen, where TVML's own lists don't fit:

```tsx
import { SimplifiedList, SimplifiedListRow } from "tvml-react/native";

<SimplifiedList summary="History" style={{ width: 900, height: 700 }}>
  {tracks.map((track) => (
    <SimplifiedListRow
      key={track.id}
      title={track.title}
      subtitle={track.artist}
      accessory={track.time}
      image={track.artwork}
      onSelect={() => open(track)}
    />
  ))}
</SimplifiedList>
```

Rows take `onSelect` and `onHighlight` like TVML elements. Needs an app launched with `TVMLReact.launch`, which registers it.
