## Overview

TVJS accepts synthetic events, so a dispatched `select` reaches the same handlers a remote press
does. Call these from Safari's Web Inspector, or a debug-only code path:

```ts
import { fireSelect, queryAll, queryByText, typeText } from "tvml-react/testing";

fireSelect(queryByText("Settings")!);
typeText(queryAll("searchField")[0], "miles");
```

Queries search the visible screens. The `fire` helpers throw for disabled elements, which a real
remote can't reach. For tests with the real remote, see [Testing](/learn/testing/).
