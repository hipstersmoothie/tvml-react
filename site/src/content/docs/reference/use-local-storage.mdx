## Overview

```tsx
const [favorites, setFavorites] = useLocalStorage<Array<string>>("favorites", []);
setFavorites((current) => [...current, id]);
```

Values are stored as JSON in TVJS's `localStorage` and survive relaunches. Every component using
the same key updates together. Keep it to settings and small lists.
